# Clipper — рабочие правила

## Версии

Каждая правка поднимает **патч**: 1.8.0 → 1.8.1 → 1.8.2. Второе число трогаем
только для крупных изменений, о которых договорились отдельно.

Версия живёт в одном месте — `__version__` в `clipper/__init__.py`. Из неё же
берётся тег релиза.

## Релиз

Сборку и публикацию делает `.github/workflows/build.yml`. Два пути:

* обычный коммит со словом `[release]` в сообщении — тег `v<__version__>`
  создаётся на этом коммите;
* тег `v*`, запушенный вручную.

Коммиты без маркера сборку не запускают — она идёт около двадцати минут.
Готовый релиз забирает автообновление внутри программы.

## Тесты

Лежат в `tools/test_*.py`, запускаются напрямую: `python tools/test_i18n.py`.
Тестам с плеером нужен видеофайл в `%TEMP%/clipper_*/*.mp4` — без него они
молча пропускаются. В CI гоняются `test_cache`, `test_i18n`, `test_self_update`.

## Язык

Строки в коде пишутся по-русски и оборачиваются в `tr()`; английский перевод
добавляется в словарь `EN` в `clipper/i18n.py`. `tools/test_i18n.py` следит,
чтобы в английском интерфейсе не осталось русского текста.

# Clipper

Приложение для Windows и macOS: вставляете ссылку на видео (YouTube, Vimeo,
TikTok, Instagram, VK, X/Twitter и ещё ~1000 сайтов через yt-dlp), оно скачивает
ролик, вы отмечаете нужный кусок на дорожке плеера и рендерите его в MP4 / H.264.

## Что умеет

- Скачивание по ссылке с выбором качества (до максимального доступного).
- Cookies из установленного браузера или из файла `cookies.txt` — для видео,
  которые видны только после входа в аккаунт.
- Выделение фрагмента прямо на дорожке плеера: тянем синие метки начала и конца,
  клик по дорожке — перемотка, красная линия — текущая позиция.
- Клавиши: `I` — начало по позиции, `O` — конец, `Пробел` — играть/пауза,
  `←` / `→` — шаг на секунду, с `Shift` — 0,1 с.
- Воспроизведение идёт только внутри выделенного фрагмента: плей начинает с его
  начала и останавливается на конце, а перематывать мышью можно куда угодно.
- Тёмная минималистичная тема: карточки вместо рамок, редкие настройки —
  в отдельном окне «Настройки», журнал разворачивается по кнопке.
- Перетаскивание: бросьте видеофайл или ссылку в любое место окна.
- Автообновление: при запуске проверяет релизы на GitHub и обновляет себя сама.
- Рендер в H.264 (libx264, yuv420p, profile high, `+faststart`) + AAC: настраиваются CRF, preset, разрешение и кадры/с.
- Режим «без перекодирования» — мгновенная нарезка потока копированием (режет по ключевым кадрам, поэтому границы могут сместиться на пару секунд).
- Можно открыть и обрезать локальный файл, без скачивания.

## Готовые сборки

Свежие файлы лежат в [релизах](https://github.com/Kostido/Clipper/releases):

| Файл | Для чего |
|------|----------|
| `Clipper.exe` | Windows, один файл, установка не нужна |
| `Clipper-portable-win64.zip` | Windows-портатив: настройки и загрузки в своей папке |
| `Clipper-macos.zip` | macOS 11+, внутри `Clipper.app` |

macOS при первом запуске ругается на приложение без подписи Apple:
правый клик по `Clipper.app` → **Открыть** → подтвердить.

## Сборка своими руками

Windows:

```bat
build_windows.bat
```

macOS:

```sh
./build_macos.sh
```

Скрипты создают виртуальное окружение, ставят зависимости, качают ffmpeg
и инструменты для YouTube, затем собирают `dist\Clipper.exe`
(плюс портативный архив) или `dist/Clipper.app`.

## Запуск из исходников

```bat
run.bat
```

или вручную:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Требуется Python 3.10+ (в CI используется 3.12).

## ffmpeg

Без ffmpeg не работают склейка дорожек при скачивании в высоком качестве и сам рендер.
Программа ищет его в таком порядке:

1. `bin\ffmpeg.exe` рядом с программой,
2. `ffmpeg.exe` в `PATH`,
3. бинарник из пакета `imageio-ffmpeg` (ставится вместе с зависимостями).

Скачать и положить в `bin\` автоматически:

```bat
python tools\fetch_ffmpeg.py
```

## Как пользоваться

1. Вставьте ссылку в поле сверху → **Скачать**. Видео откроется в плеере.
2. Выделите фрагмент на дорожке под плеером: тяните левую и правую метки.
   Точнее — подведите позицию кнопками ±0,1 / ±1 с и нажмите `I` или `O`.
   Кнопкой **▶ Фрагмент** можно проверить результат.
3. Выберите CRF (меньше — качественнее и тяжелее; 18–23 — рабочий диапазон),
   preset (скорость кодирования) и при желании разрешение/fps.
4. **Отрендерить фрагмент…** → укажите имя файла. Готовый MP4 совместим
   с монтажками, соцсетями и любым плеером.

## Замечания

- Скачивайте только то, на что у вас есть права: авторский контент и условия
  использования сайтов никто не отменял.
- Прогресс рендера считается по выводу `-progress` ffmpeg, поэтому проценты реальные.
- Настройки папки загрузки, качества, CRF и preset запоминаются между запусками.

## Cookies

Часть площадок (например, Vimeo) вообще не отдаёт видео анонимно. Тогда нужны
cookies залогиненного аккаунта — двумя способами:

0. **Авто** (по умолчанию) — программа сначала пробует без cookies, а если сайт
   требует вход, сама перебирает установленные браузеры и берёт первые
   подходящие. Сработавшие cookies сохраняются в
   `%APPDATA%\Clipper\cookies\<сайт>.txt` — **браузер нужно закрыть ровно
   один раз**, дальше скачивание идёт из этого файла при любом состоянии
   браузера. Сохраняются только cookies того сайта, откуда качали.
   Когда сессия на сайте истечёт, программа снова попросит закрыть браузер.
1. **Из браузера** — выберите его в списке «Cookies из браузера».
   Браузер при этом должен быть **полностью закрыт**, иначе он держит базу
   cookies заблокированной. Chrome 127+ шифрует базу через DPAPI и может не
   отдать cookies вовсе.
2. **Из файла** — кнопка «Файл cookies…». Экспортируйте `cookies.txt`
   (формат Netscape) расширением вроде «Get cookies.txt LOCALLY».
   Работает при запущенном браузере, путь запоминается между запусками.

Видео с DRM (часть Vimeo-роликов) не скачиваются никакими способами —
поток зашифрован на стороне сайта.

## Прокси и VPN

В поле «Прокси» можно задать свой адрес (`socks5://127.0.0.1:10808`,
`http://user:pass@host:port`) — пусто означает «как в настройках Windows».
Это нужно для сайтов, которые не отдают видео на IP датацентров и VPN:
TikTok и Instagram проверяют репутацию адреса, и с датацентрового IP
возвращают заглушку или 403, даже когда в браузере всё открывается.

Программа использует системные настройки прокси Windows. Если прокси включён,
а VPN-клиент не запущен, скачивание падало бы с `Failed to connect to 127.0.0.1`.
Теперь при такой ошибке выполняется повторная попытка напрямую, минуя прокси,
и только если и она не прошла — выводится объяснение.

## Обновления

Программа при запуске спрашивает GitHub про последний релиз и, если он новее,
предлагает обновиться. Скачивает `Clipper.exe` из релиза, проверяет размер и
подпись файла, переименовывает текущий exe в `Clipper.old.exe`, ставит новый
на его место и предлагает перезапуск. Старый файл удаляется при следующем старте.
Поведение переключается в меню **Программа → Проверять при запуске**;
там же — **Проверить обновления** вручную.

Из исходников программа себя не подменяет, а подсказывает `git pull`.

### Как выпустить новую версию

```bat
publish_release.bat 1.2.0 "Что нового"
```

Скрипт пропишет версию в `clipper/__init__.py`, соберёт exe, запушит тег и
опубликует релиз с файлом `dist\Clipper.exe` через GitHub CLI. Автообновление
ищет в релизе ассет ровно с именем `Clipper.exe` — если выложить файл под другим
именем, обновление не найдёт, что качать.

## YouTube

YouTube отдаёт популярные ролики только тем, кто предъявит PO-токен и правильно
посчитает подпись ссылки на JavaScript. Поэтому в `bin/` лежат два помощника,
и оба попадают внутрь exe:

- `qjs.exe` (~2 МБ) — движок JavaScript quickjs-ng, считает подписи;
- `rustypipe-botguard.exe` (~41 МБ) — генератор PO-токенов.

Скачать их вручную:

```bat
python toolsetch_youtube_tools.py
```

Программа сначала пробует обычный путь и переключается на web-клиент с PO-токеном
только при ошибке 403 — так обычные ролики качаются без лишних задержек.

## Самодиагностика

```bat
Clipper.exe --selftest report.txt
Clipper.exe --selftest report.txt --download https://youtu.be/ID
```

Пишет в файл, что нашлось внутри сборки (ffmpeg, JS-движок, генератор токенов,
плагины) и, если указан `--download`, результат пробного скачивания. Полезно,
когда что-то не работает и надо понять, чего не хватает.

## Когда сайт «не пускает»

Порядок обходных путей применяется автоматически и накапливается: мёртвый
системный прокси → прямое соединение, таймаут → IPv4, антибот-защита →
обычный TLS с браузерными заголовками, 403 на YouTube → PO-токен и web-клиент,
DRM → перебор форматов. Если и это не помогло, подключаются cookies: сначала
сохранённые, потом из установленных браузеров.

Что остаётся вне власти программы: блокировка по репутации IP. Если сайт
отвечает заглушкой на любой запрос с вашего адреса, помогает только другой
выход в сеть — впишите другой прокси в соответствующее поле.

## Портативный режим

В архиве `Clipper-portable-win64.zip` рядом с программой лежит файл
`portable.txt`. Пока он на месте, Clipper ничего не пишет в реестр и профиль:

```
ClipperData\settings.ini   настройки
ClipperData\cookies\       сохранённые cookies сайтов
Downloads\                 скачанные видео
```

Папку можно носить на флешке. Удалите `portable.txt` — программа вернётся к
обычному режиму. Тот же файл можно создать рядом с обычным `Clipper.exe`.

## Сборки в CI

[.github/workflows/build.yml](.github/workflows/build.yml) собирает Windows-exe,
портативный архив и `Clipper.app` на macOS-раннере. Запуск вручную через
Actions или пушем тега:

```bat
git tag v1.2.0
git push origin v1.2.0
```

Файлы прикрепляются к релизу с этим тегом — автообновление в программе
ищет ассет с именем `Clipper.exe` (Windows) или `Clipper-macos.zip` (macOS).
На macOS программа себя не подменяет, а открывает страницу релизов.

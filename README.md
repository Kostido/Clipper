# Clipper

Простое Windows-приложение: вставляете ссылку на видео (YouTube, Vimeo, TikTok,
Instagram, VK, X/Twitter и ещё ~1000 сайтов через yt-dlp), оно скачивает ролик,
вы отмечаете нужный кусок и рендерите его в MP4 / H.264.

## Что умеет

- Скачивание по ссылке с выбором качества (до максимального доступного).
- Cookies из установленного браузера — для видео, которые видны только после входа в аккаунт.
- Встроенный проигрыватель: перемотка, покадровая подстройка кнопками ±0.1 / ±1 с, предпросмотр выбранного фрагмента.
- Метки начала и конца прямо с текущей позиции плеера, ручной ввод таймкодов (`1:05`, `01:02:03.250`).
- Рендер в H.264 (libx264, yuv420p, profile high, `+faststart`) + AAC: настраиваются CRF, preset, разрешение и кадры/с.
- Режим «без перекодирования» — мгновенная нарезка потока копированием (режет по ключевым кадрам, поэтому границы могут сместиться на пару секунд).
- Можно открыть и обрезать локальный файл, без скачивания.

## Быстрый старт (готовый .exe)

```bat
build_windows.bat
```

Скрипт создаст виртуальное окружение, поставит зависимости, скачает ffmpeg
и соберёт `dist\Clipper.exe` — один файл, который можно скопировать куда угодно.

## Запуск из исходников

```bat
run.bat
```

или вручную:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Требуется Python 3.10+.

## ffmpeg

Без ffmpeg не работают склейка дорожек при скачивании в высоком качестве и сам рендер.
Программа ищет его в таком порядке:

1. `bin\ffmpeg.exe` рядом с программой,
2. `ffmpeg.exe` в `PATH`,
3. бинарник из пакета `imageio-ffmpeg` (ставится вместе с зависимостями).

Скачать и положить в `bin\` автоматически:

```bat
python tools\fetch_ffmpeg.py
```

## Как пользоваться

1. Вставьте ссылку в поле сверху → **Скачать**. Видео откроется в плеере.
2. Доведите позицию до нужного места → **Начало = текущая позиция**, то же для конца.
   Кнопкой **▶ Проиграть фрагмент** можно проверить результат.
3. Выберите CRF (меньше — качественнее и тяжелее; 18–23 — рабочий диапазон),
   preset (скорость кодирования) и при желании разрешение/fps.
4. **Отрендерить фрагмент…** → укажите имя файла. Готовый MP4 совместим
   с монтажками, соцсетями и любым плеером.

## Структура

```
main.py                 точка входа
clipper/app.py          интерфейс и вся логика окна
clipper/downloader.py   обёртка над yt-dlp
clipper/ffmpeg_tools.py поиск ffmpeg, probe, сборка и запуск команды рендера
clipper/workers.py      QThread-воркеры (интерфейс не подвисает)
clipper/timecode.py     разбор и печать таймкодов
tools/fetch_ffmpeg.py   загрузка ffmpeg в bin/
Clipper.spec            конфиг PyInstaller
```

## Замечания

- Скачивайте только то, на что у вас есть права: авторский контент и условия
  использования сайтов никто не отменял.
- Прогресс рендера считается по выводу `-progress` ffmpeg, поэтому проценты реальные.
- Настройки папки загрузки, качества, CRF и preset запоминаются между запусками.
